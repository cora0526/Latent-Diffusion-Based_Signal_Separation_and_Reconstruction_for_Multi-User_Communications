# Latent Diffusion Based Signal Separation
## 中文 (English is down below)
## 專案介紹

本專案實作一套基於潛在擴散模型（Latent Diffusion Model）的訊號分離系統，結合 VAE-GAN 與條件式去噪擴散機率模型（Conditional DDPM），實現混合潛在表示（Latent Representation）的分離與影像重建。

整體訓練流程分為兩個階段：

1. **VAE-GAN 預訓練**：訓練 Encoder 與 Generator，學習影像的潛在表示並進行影像重建。
2. **DDPM Separator 訓練**：使用預訓練 Encoder 產生的潛在表示，訓練 DDPM 模型進行訊號分離。

完成訓練後，可以使用測試程式評估模型效能並儲存結果。

## 1. 環境需求

- Python 3.11
- PyTorch 2.10.0
- Torchvision 0.25.0
- NVIDIA GPU（選用，建議訓練時使用）

### 使用 GPU（CUDA 12.6）

```bash
pip install torch==2.10.0+cu126 torchvision==0.25.0+cu126 --index-url https://download.pytorch.org/whl/cu126
```

### 不使用 GPU（CPU）

```bash
pip install torch==2.10.0 torchvision==0.25.0
```

安裝其他相依套件：

```bash
pip install -r requirements.txt
```

## 2. 模型訓練

模型訓練分為兩個階段，必須先完成 VAE-GAN 的預訓練，才能開始訓練 DDPM Separator。

### Step 1：預訓練 VAE-GAN

執行：

```bash
python train_vae_gan.py
```

預訓練完成後，模型權重將儲存在：

```text
./save_model/
```

### Step 2：訓練 DDPM Separator

完成 VAE-GAN 預訓練後，執行：

```bash
python train_ddpm.py
```

DDPM Separator 會使用預訓練 Encoder 產生的潛在表示進行訓練。

完成此步驟後，即完成兩個階段的模型訓練。

## 3. 模型測試

完成 VAE-GAN 與 DDPM Separator 的訓練後，執行：

```bash
python test_vae_gan_ddpm.py
```

測試程式將載入預訓練模型並進行評估。

測試結果將儲存在：

```text
./save_data/
```

## 4. 快速開始

依序執行下列指令：

```bash
# Step 1：預訓練 VAE-GAN
python train_vae_gan.py

# Step 2：訓練 DDPM Separator
python train_ddpm.py

# Step 3：執行模型測試
python test_vae_gan_ddpm.py
```

## English
## Introduction

This project implements a latent diffusion-based signal separation framework using a pretrained VAE-GAN and a conditional Denoising Diffusion Probabilistic Model (DDPM).

The training process consists of two stages:

1. **VAE-GAN Pretraining:** Train the encoder and generator to learn latent representations and reconstruct images.
2. **DDPM Separator Training:** Train the DDPM model to separate mixed latent representations.

After training, the pretrained models can be evaluated using the provided testing script.

## 1. Environment Requirements

- Python 3.11
- PyTorch 2.10.0
- Torchvision 0.25.0
- NVIDIA GPU (optional, recommended for training)

### GPU Installation (CUDA 12.6)

```bash
pip install torch==2.10.0+cu126 torchvision==0.25.0+cu126 --index-url https://download.pytorch.org/whl/cu126
```

### CPU Installation (Without GPU)

```bash
pip install torch==2.10.0 torchvision==0.25.0
```

Install the remaining project dependencies:

```bash
pip install -r requirements.txt
```

## 2. Training

The training process consists of two stages. The VAE-GAN must be pretrained before training the DDPM separator.

### Step 1: Pretrain the VAE-GAN

Run:

```bash
python train_vae_gan.py
```

The pretrained models will be saved in:

```text
./save_model/
```

### Step 2: Train the DDPM Separator

After completing VAE-GAN pretraining, run:

```bash
python train_ddpm.py
```

The DDPM separator is trained using the latent representations generated by the pretrained encoder.

Once this stage is completed, the model training process is finished.

## 3. Testing

After both training stages are completed, run:

```bash
python test_vae_gan_ddpm.py
```

The test script evaluates the pretrained VAE-GAN and DDPM separator.

Test results will be saved in:

```text
./save_data/
```

## 4. Quick Start

Run the following commands in order:

```bash
# Step 1: Pretrain VAE-GAN
python train_vae_gan.py

# Step 2: Train DDPM separator
python train_ddpm.py

# Step 3: Test pretrained models
python test_vae_gan_ddpm.py
```

## 5. Output Directories

| Directory | Description |
|---|---|
| `./save_model/` | Stores pretrained model checkpoints |
| `./save_data/` | Stores testing results |
